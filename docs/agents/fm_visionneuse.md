## `focus.py` (aujourd'hui les sous-modules ci-dessus)

- `focus.py` : état « focus » (se concentrer sur un objet : aperçu image/turntable pour l'instant, d'autres types à venir) ; `FocusOverlay` anime l'objet de l'inspecteur au centre quand on masque les colonnes. Tout le nouveau code de cet état va ici. **Visionneuse** (colonnes masquées, image seule au centre ; orchestration `PipelineBrowser._enter_viewer` / `_viewer_go` / `_sync_viewer_chrome`, test `tests/test_focus_viewer.py`, sonde de parcours sur un vrai dossier `tests/_probe_viewer.py` : temps bloquant à garder sous ~10 ms par cran) : liste = fichiers À APERÇU de la colonne du fichier en cours (`PREVIEWABLE_EXTENSIONS` : images, mais aussi .ma, .obj, .blend, .fbx, .abc, PSD, EXR, PDF, plans, vidéos…), dans son ordre, lue UNE fois à l'entrée (`_scan_viewer_paths`, `ROLE_ISDIR`, aucun `stat` par fichier) dans `_viewer_paths` / `_viewer_index` — c'est la vérité pendant le focus : la colonne et l'inspecteur (masqués) ne suivent qu'au repos (`_viewer_sync`, 700 ms, repoussé tant que l'image bouge) ou aussitôt au retour des colonnes (`_flush_viewer_sync`, avant la capture du retour). Images courantes (`IMAGE_EXTENSIONS`) décodées EN FOND par `FocusImageLoader` (`QImageReader`, orientation EXIF, plafond 8192 px, version déjà ajustée à l'écran + image pleine pour le zoom, LRU ~700 Mo, `ready`) ; taille réelle lue dans l'entête (`natural_size`) pour poser l'image à sa place définitive avant qu'elle soit décodée (l'aperçu 640 px puis la pleine définition la remplacent sans bouger : `FocusOverlay.upgrade`) ; voisines préchargées dans le sens de la marche (`_prefetch_viewer` ; non-images : aperçus disque lus après le glissement). JAMAIS de décodage d'image sur le fil de l'interface. Changement d'image = RUBAN (`FocusOverlay.show_image(delta)` : décalage `_shift` en images, cumulé et borné à 3 pour les crans rapides, qui revient à 0 en 330 ms ; voisines par le rappel `neighbours(k)` = `_viewer_neighbour`, mémoire seulement, petite vignette des colonnes à défaut) ; extrémités = rebond (`bump`). Zoom animé autour du curseur (Ctrl+molette, `zoom_by` ; point fixe relevé UNE fois par geste, `_anchor`), image zoomée déplacée à la souris, toujours couvrante (`_clamp_pan`) ; changer d'image dézoome.
