## Module CAD du board (`fm_cad/cad*.py`, phase 1 + arcs, cercles, polylignes, DÉCALER, CHANFREIN, RACCORD, TEXTES, DÉCOMPOSER, AJUSTER À LA AUTOCAD)

Demande de l'utilisateur (octobre 2026, cahier des charges « module CAD professionnel intégré à MRO ») : dessin technique 2D à la manière d'AutoCAD DANS la page MRO (le board), développé PAR PHASES — phase 1 faite (lignes, accrochages, calques, barre de commande) ; de la phase 2, POLYLIGNE, CERCLE, ARC (avancés pour faire les outils correctement, accord de l'utilisateur) ; de la phase 3, DÉCALER, CHANFREIN, RACCORD, ROTATION, MIROIR, ÉCHELLE, AJUSTER ; RECTANGLE ; de la phase 4, les hachures et les TEXTES (TEXTE, MTEXTE) ; de la phase 3, DÉCOMPOSER ; de la phase 5, les cotations (non associatives) ; le reste déclaré, jamais présenté comme disponible : 2 primitives (ELLIPSE, POLYGON), 3 modifications (EXTEND, STRETCH, BREAK, JOIN, ARRAY), 5 cotations associatives, 6 optimisation. Référence = comportement documenté d'AutoCAD (LINE, OSNAP, coordonnées, calques) ; aucun code repris.
- FICHIERS (couches, chacune n'importe que les précédentes) : `cad_geometry` (pur : conversions, projections, intersections, motifs, `GridIndex`), `cad_shapes` (pur : géométrie des entités en PRIMITIVES `("segment", a, b)` / `("arc", c, r, a0, ouverture)` — tessellation, emprise, plus proche point, intersections segment / arc / cercle, renflements, arcs par 3 points, poignées, déplacement), `cad_tools` (pur : DÉCALER, CHANFREIN, RACCORD ; une chaîne = message d'impossibilité), `cad_model` (pur : calques, entités, ByLayer), `cad_input` (pur : grammaire des saisies), `cad_snap` (pur : moteur d'accrochage), `cad_items` (`CadLineItem`, rendu), `cad_commands` (commandes + registre), `cad_overlay` (rendu temporaire), `cad` (`CadController` : point d'entrée, coordination), `cad_ui` (barres, panneaux, fenêtres). `model` importe `cad_model` (type `cad_line` dans `DEFAULTS`, `normalize_line`) ; `scene` importe `cad_items` (enregistre le type dans `ITEM_CLASSES`).
- INTÉGRATION NATIVE : une entité CAD = un ÉLÉMENT du board (`cad_line`) : sur la page, enregistrée dans le `.mro`, annulée (`StateCommand`), copiée / collée / dupliquée / exportée comme les autres, visible quand le mode CAD est coupé (et déplaçable / supprimable par le board). Calques et propriétés courantes dans `page["cad"]` (versionné `CAD_VERSION`, absent tant que le CAD n'a pas servi : un board sans CAD s'écrit EXACTEMENT comme avant ; changements de calques = état `__page__`, donc annulables). RÈGLE : ne jamais modifier sur place un dictionnaire de `page["cad"]` (les états d'annulation le partagent) — `cad_model.copy_cad` puis `CadController.set_cad` / `set_cad_and_items`. Champs inconnus (version plus récente) gardés : entité, extrémités, calques, `page["cad"]`.
- COORDONNÉES (jamais mélangées) : ÉCRAN (pixels du viewport : tolérances, marqueurs, poignées) ; SCÈNE (unités du board, Y vers le bas) ; DOCUMENT (mêmes unités, Y vers le HAUT, angles trigonométriques, 0 = est, comme AutoCAD) : `doc = (scène.x, -scène.y)` (`cad_geometry.to_doc` / `to_scene`, `CadController.view_to_doc` / `doc_to_view` en flottants). Géométrie en double précision, `p1` / `p2` jamais arrondis ; la place Qt d'une ligne (déplacement du board, collage) est ajoutée aux points (`CadLineItem.points`) et repliée à l'enregistrement (`to_dict` : x = y = 0).
- LIGNE (`CadLineItem`) : calque, couleur / épaisseur / type de ligne `ByLayer` ou override (résolus AU DESSIN par `cad_model.resolve`, jamais recopiés : changer le calque met à jour ses lignes ByLayer), échelle du type, extrémités `end1` / `end2` : coupe franche, arrondi (demi-cercle AU-DELÀ du point, comme la terminaison ronde), border radius 0-100 % de la demi-épaisseur (DANS la coupe ; deux extrémités trop proches : rayons réduits ensemble) — contour exact généré par `line_outline` ; épaisseur en unités du board (saisie / affichée dans l'unité de mesure), 0 (ou < 1 pixel à l'écran) = trait fin d'un pixel ; motifs (types de ligne réglables, voir TYPES DE LIGNE : unité de mesure × échelle de la page × échelle de l'entité ; trop serrés à l'écran : trait continu). Longueur / angle toujours entre les points de référence (accrochages aussi). Aucune image gardée (`NO_CACHE`, `_set_item_cache` la saute) ; contours / motifs en cache, refaits si géométrie ou propriétés changent. Calque masqué : invisible, ni accrochable ni sélectionnable ; calque verrouillé (ou verrou du board) : `locked()` vrai, ni modifié ni déplacé ni supprimé, mais ACCROCHABLE.
- COMMANDES (`cad_commands.REGISTRY`, alias anglais / français, `_` et `-` ignorés) : une seule implémentation lancée par la barre d'outils, la barre de commande ou une touche (`CadController.run`). LINE / L / LIGNE (segments indépendants ; options annUler / Clore ; Entrée au 1er point = reprise à la dernière extrémité ; Échap GARDE les segments ; UNE étape d'annulation par commande, segments ajoutés hors annulation puis `commit_created`), MOVE / M, COPY / CO (copies multiples, annUler), ERASE / E (sélection préalable ou invite « Choix des objets » : clic, fenêtre, TOUT, Entrée), poignées (`GripCommand` : clic-clic ou glisser ; ÉTIREMENT des extrémités — toutes les poignées au même point suivent —, DÉPLACEMENT par le milieu, Entrée = mode suivant, option Copier), LAYER / LA, PROPERTIES / PR (Ctrl+1), OSNAP / OS / DS, U, REDO, ORTHO, POLAR, GRID, SNAP, HELP / AIDE, CADQUIT. Commande prévue tapée = message « prévue en phase N » ; Entrée / Espace à « Commande : » = répéter la dernière.
- SAISIE (`cad_input.parse`) : `x,y` absolu (barre de commande ; RELATIF en saisie dynamique pour un point suivant, `#x,y` absolu), `@dx,dy`, `@d<a`, `d<a`, `@` seul, distance directe (direction de l'élastique : ORTHO / polaire / suivi compris), `<a` = angle imposé, `END` / `MID` / `PER`… = accrochage ponctuel (`NON` = aucun), options par leurs capitales. Séparateur décimal = le POINT, toujours (« 12,5 » est un point) ; saisie non reconnue = message, jamais de géométrie devinée. Saisie dynamique (F12) : champs près du curseur (X / Y, ou distance / angle), Tab verrouille la valeur tapée et passe au champ suivant.
- ARCS, CERCLES, POLYLIGNES (octobre 2026) : types `cad_arc` (center, radius, start, end : sens trigonométrique, comme le DXF), `cad_circle` (center, radius), `cad_pline` (vertices [[x, y, renflement]], closed — renflement = LWPOLYLINE du DXF) ; mêmes propriétés que la ligne (`cad_model.PROP_DEFAULTS`, `ENTITY_DEFAULTS`, `normalize_entity`, `new_entity_values`). Rendu : `cad_items.CadCurveItem` HÉRITE de `CadLineItem` (tout le code qui teste `CadLineItem` — sélection, lots, calques, pipette — les prend) ; API commune `prims()` / `doc_bounds()` / `outline(tol)` / `geometry()` (place Qt repliée) / `grips()` ; traits épais = chemins EXACTS (`scene_path` : arcs de Qt, mêmes angles que le document car Y est retourné ; `stroke_outline` : coupe franche + disque aux bouts « arrondi », angles en onglet ; border radius des courbes rendu en coupe franche) ; traits fins = courbes TESSELLÉES en petits traits (même `drawLines` que les lignes dans le lot) à la finesse du zoom `tess_band` (puissance de 2), que la vue ne change qu'à la FIN d'un zoom (`BoardView.set_zoom` hors geste, `_zoom_settled` → `scene.cad_tess_zoom`) : régénération différée, le lot ne refait que ses listes qui contiennent des courbes ; motifs le long de l'abscisse curviligne (`cad_shapes.sub_prims`). Commandes POLYLIGNE (PL : segments ou Arc TANGENT au précédent, Ligne, Clore, annUler ; créée à la fin en une étape), CERCLE (C : centre + rayon / Diamètre, 3P, 2P), ARC (A : 3 points, ou Centre / départ / extrémité). Accrochages des arcs : extrémités, milieu, centre (proposé en survolant le trait, classé par sa vraie distance), quadrants, proche, perpendiculaire, tangente depuis le point de base, intersections segment / arc / arc. Poignées : arc = extrémités / milieu (arc refait par 3 points) / centre (déplace) ; cercle = centre + quadrants (rayon) ; polyligne = sommets + milieux des segments (`cad_shapes.grip_edit`, commande `GripCommand` générique). Fenêtre de sélection (contenu / capture) sur l'emprise / la tessellation. Panneau Propriétés : objet, centre, rayon, angles, sommets, longueur (lecture seule). DXF : export ARC / CIRCLE / LWPOLYLINE (renflements) ; import ARC / CIRCLE / LWPOLYLINE en VRAIES entités (`cad_import._native` ; extrusion autre que +Z, POLYLINE, ELLIPSE, SPLINE : toujours approchés par des lignes). Mesure (3 000 lignes + 2 000 arcs / cercles, fenêtre réelle) : zoom 31 / 35 ms, pan 20 / 25 ms, mouvement 2,2 / 4,2 ms (p50 / p95). Tests `CurveGeometryTest`, `CurveEntitiesTest`.
- DÉCALER / CHANFREIN / RACCORD (`cad_tools` + commandes OFFSET / O, CHAMFER / CHA, FILLET / F / ARRONDI ; boutons de la barre CAD ; valeurs MÉMORISÉES pour la session dans `CadController.tool_memory`) : invites de VALEUR (`Prompt.value` = "length" — unité du dessin — ou "angle" : le nombre tapé va à `command.value`), choix d'objet À EFFET IMMÉDIAT (`IMMEDIATE_PICK`, point cliqué = `ctx.last_pick_doc`), mots-clés aussi à l'invite de choix (`_submit_select`), APERÇU AU SURVOL d'un objet à choisir (`command.hover_ghosts(objet survolé, curseur)`, posé par `overlay_state`), une étape d'annulation par opération (`ctx.apply_edit(changements, créations, texte)`). DÉCALER : distance (tapée ou deux points) ou Par ; boucle objet → côté (aperçu) jusqu'à Entrée / Échap ; annUler = dernier décalage ; lignes, arcs, cercles (rayon ≤ 0 refusé avec message), polylignes (primitives décalées puis sommets RACCORDÉS à l'intersection des primitives prolongées, comme AutoCAD ; fermées comprises). CHANFREIN : Distance (d1, d2), Angle (longueur + angle, loi des sinus), Méthode, Ajuster / Non ajuster, Polyligne (tous les sommets entre deux segments droits), Multiple ; deux lignes (côté gardé = celui du clic, lignes coupées OU prolongées, sens p1 / p2 gardé) ou deux segments voisins d'une même polyligne ; distances 0 = coin vif ; parallèles / distance trop grande = message. RACCORD : Rayon, Ajuster, Polyligne, Multiple ; ligne-ligne, ligne-arc / cercle, arc-arc (cercle tangent aux deux choisi d'après les points cliqués : tangences les plus proches des clics ; un cercle complet n'est jamais coupé), deux segments voisins d'une polyligne (sommet remplacé par deux sommets + renflement) ; rayon 0 = coin vif ; parallèles, rayon trop grand = message. Non fait : raccord polyligne ↔ autre objet (message), raccord de lignes parallèles par un demi-cercle. Tests `ModifyToolsTest`, `CurveGeometryTest`.
- CLICS PERDUS (signalé : « environ un clic sur deux est ignoré ») — cause PROUVÉE par de vrais clics Windows (SendInput) journalisés : quand deux clics sont rapides et proches, Qt REMPLACE le 2e appui par un événement de DOUBLE-CLIC (séquence reçue : appui, relâche, DOUBLE, relâche — jamais de 2e appui) ; `mouse_double_click` ne traitait le double-clic comme un appui qu'à une invite de POINT : ailleurs (2e coin d'une fenêtre de sélection, 2e objet à « Choix des objets », 2e clic de sélection) il était jeté, et sa relâche aussi faute d'appui. Correction : un double-clic compte TOUJOURS comme un appui (`mouse_press(log=False)`) ; hors commande, sur un objet, sa relâche choisit le plus proche (pas de cycle entre objets superposés) et ouvre ses propriétés (`_press_double`) ; seuil clic / glisser `CLICK_PX` = 4 px. - MOTEUR GPU DU CAD (octobre 2026, demande de l'utilisateur après l'essai raté : `fm_cad/cad_gpu.py`, réglage Module CAD > Affichage « Rendu GPU (OpenGL) des entités CAD », `board_cad_gpu`, ÉTEINT par défaut ; le rendu par lots du processeur reste le SECOURS). Une entité = N instances (segments, 12 float32 : a, b relatifs à l'origine du lot | demi-épaisseur, rayons, codes de terminaison | couleur), lots de `CHUNK` = 2048 entités (origine propre, upload des seuls lots modifiés, lots hors écran ignorés) ; courbes tessellées (`tol` = finesse, joints arrondis `JOIN`), motifs de ligne = instances (trait continu sous le seuil « dense », `GpuStore.zoom_changed`). Fragment shader : couverture analytique (SDF de boîte arrondie), mélange en lumière linéaire (même formule que `linear_blend_table`), traits fins nets, `GL_MAX` pour fusionner les couvertures. MODE « PUR CAD » (`set_pure` : seulement des entités CAD sur la page et grille en lignes) : la couche est opaque et dessine fond + grille + CAD (FBO puis composition), la vue raster est figée ; sinon couche translucide posée au-dessus du raster. Sélection, aperçus, réticule peint, infobulles : `QPainter(self)` dans `paintGL` après le tracé brut (`paint_hook` → `BoardView._paint_gpu_overlay`) ; zones des panneaux flottants effacées (`_gpu_obstacles`).
